# 🧠 Online Quiz System

A Java-based Quiz Application that allows users to attempt quizzes, calculate scores, and view results using a MySQL database.

---

## 🚀 Features

- 🔐 User Authentication (Login System)
- 📝 Quiz with fixed/random questions
- ⏱️ Score Calculation
- 📊 Result Display
- 🏆 Leaderboard System
- 🗄️ MySQL Database Integration

---

## 🛠️ Tech Stack

- Java
- MySQL
- JDBC
- VS Code
