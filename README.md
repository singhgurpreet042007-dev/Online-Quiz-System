# 🧠 Online Quiz System

A Java-based Quiz Application that allows users to attempt quizzes, calculate scores, and view results using a MySQL database.

---

## 🚀 Features

* 🔐 User Authentication (Login System)
* 📝 Quiz with 5 Questions
* ⏱️ Automatic Score Calculation
* 📊 Result Display Page
* 🏆 Leaderboard System
* 🗄️ MySQL Database Integration

---

## 🛠️ Tech Stack

* **Java**
* **MySQL**
* **JDBC**
* **VS Code**

---

---

## ⚙️ How to Run

1. Install Java (JDK 17 recommended)
2. Install MySQL Server
3. Create database and tables
4. Add MySQL Connector JAR in `lib/` folder
5. Open project in VS Code
6. Run main file

---

## 🧪 Working Flow

1. User logs in
2. Starts quiz
3. Attempts questions
4. Submits answers
5. Score is calculated
6. Result is displayed
